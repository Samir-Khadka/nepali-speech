## The rule

**No target justifies collecting personal data.** All metadata —
province, age band, gender, urban/rural, device — is **optional and
self-reported**. We never ask for a name, email, phone number, or any
other identifying detail, and recordings are never linked to an identity.
If a target cannot be measured without personal data, it stays unmeasured.

## Targets

### By province (all 7, roughly even)

| Province | Target share of approved recordings |
| --- | --- |
| Koshi | ~14% (~7 hours) |
| Madhesh | ~14% (~7 hours) |
| Bagmati | ~14% (~7 hours) |
| Gandaki | ~14% (~7 hours) |
| Lumbini | ~14% (~7 hours) |
| Karnali | ~14% (~7 hours) |
| Sudurpashchim | ~14% (~7 hours) |

Roughly even on purpose: the dataset should represent how Nepali is
spoken across the whole country, not only where recruiting is easiest.
A province being behind is a signal to do more outreach there — never a
reason to pressure anyone or to collect identifying data.

### Gender

| Group | Target |
| --- | --- |
| Women | ~50% |
| Men | ~50% |
| Other / prefer not to say | welcome; counted only when self-reported |

Aim for balance. Gender is optional and self-reported; "prefer not to
say" is always a valid answer and is never followed up on.

### Age bands

| Age band | Target |
| --- | --- |
| Under 18 (with guardian consent) | welcome |
| 18–30 | ~35% |
| 31–45 | ~30% |
| 46–60 | ~20% |
| 61+ | ~15% |

Older speakers are especially valuable — they are the most
under-represented in existing Nepali speech data. Age band is optional
and self-reported.

### Urban / rural

| Setting | Target |
| --- | --- |
| Urban | ~50% |
| Rural | ~50% |

Rural voices matter most for the farmer phone-assistant use case, and
are the hardest to reach — prioritise rural outreach (community radio,
schools, local groups) rather than only online channels.

### Device variety

| Device / microphone | Target |
| --- | --- |
| Android phones | broad mix of brands and price ranges |
| iPhones | welcome |
| Basic / older phones | welcome — low-end devices are valuable data |
| Headsets / earphones with mic | welcome |
| Laptop / desktop mic | welcome |

Do **not** aim for clean studio audio. Phone-quality recordings in
ordinary rooms are exactly what the dataset is for. A mix of devices,
microphones, and everyday background conditions is a feature, not a flaw.

## How progress is tracked

- Count **approved recordings and approved hours only** — raw submissions
  don't count until reviewed.
- Track shares by province, gender, age band, urban/rural, and device
  **only from optional self-reported metadata**, and report "not stated"
  as its own category.
- Review the balance monthly during Phase 2 and steer outreach toward
  the groups furthest behind.
- Never contact a contributor to ask for missing metadata.
